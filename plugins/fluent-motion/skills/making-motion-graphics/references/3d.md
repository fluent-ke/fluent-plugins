# 3D and generated plates

Three routes, from lightest to heaviest: Three.js drawn inside the comp for 3D accents, a Blender plate for real light and physics, and a generated plate from a video model for people and live scenes. Whichever route, words are drawn by the comp, never baked into the 3D or the generation.

## Three.js inside the comp

For a spinning metallic mark, cards orbiting in space, a device rising Apple-style or a product on a turntable, render Three.js into an off-screen WebGL canvas and draw it onto the frame. No plate, no second render, and it re-times with the scene. Headless Chromium draws WebGL (tested: a lit, metallic torus knot at full size, 4 workers).

`npm install three` in the film folder, then in comp.html's Assets block, above the `window.ready` line:

```js
let THREE,gl,sc3,cam3,hero;
const three=import('./node_modules/three/build/three.module.js').then(M=>{THREE=M;
  gl=new THREE.WebGLRenderer({antialias:true,alpha:true,preserveDrawingBuffer:true});gl.setPixelRatio(1);gl.setSize(W,H,false);
  gl.toneMapping=THREE.ACESFilmicToneMapping;sc3=new THREE.Scene();cam3=new THREE.PerspectiveCamera(30,W/H,.1,100);cam3.position.set(0,0,12);
  sc3.add(new THREE.HemisphereLight(0xffffff,0x202030,1.2));                                 // soft base
  const key=new THREE.DirectionalLight(0xffe0c0,3);key.position.set(-4,5,6);sc3.add(key);     // warm key, top left
  const rim=new THREE.DirectionalLight(0x46ff5e,4);rim.position.set(5,-2,-6);sc3.add(rim);    // accent rim from behind
  hero=new THREE.Mesh(new THREE.TorusKnotGeometry(1.4,.45,220,32),new THREE.MeshStandardMaterial({color:0x5b2a86,metalness:.7,roughness:.25}));sc3.add(hero)});
const U3=H/(2*12*Math.tan(15*Math.PI/180));                   // px per world unit at z=0 (camera z 12, fov 30): x = (px - W/2)/U3
function draw3(a){hero.rotation.set(b*.6,b*.9,0);hero.scale.setScalar(spring(a,{z:.55}));gl.render(sc3,cam3);
  ctx.save();ctx.setTransform(1,0,0,1,0,0);ctx.drawImage(gl.domElement,0,0);ctx.restore()}
```

Add `three` to the `Promise.all` in `window.ready` so no frame renders before the module loads, and call `draw3(a)` inside the scene after its background, with `a` the scene's start beat. To put the object at a pixel position, convert with `U3` (about 299 px per unit here): `hero.position.x=(px-W/2)/U3`, `hero.position.y=(H/2-py)/U3`. Everything in `draw3` is set from `b` or `t` on every call: no `requestAnimationFrame`, no clock, no three.js `Clock`, no state from the last frame. For a logo, extrude the supplied SVG with `SVGLoader` and `ExtrudeGeometry` (loaders are in `three/examples/jsm/`), never retype it in a 3D font.

## Blender plates

A 3D plate is a Blender shot rendered headless to a **transparent PNG sequence**. The comp plays it like footage, so the 3D work and the motion graphics stay in one timeline: the comp can scale, lift and shake the plate, draw text and shockwaves over it, and hand a 3D object into a flat logo. Use it when a shape needs real light, depth of field or physical motion (a logo that assembles, a product that turns, a swarm that forms a mark). For flat, graphic motion the canvas is faster and needs no plate.

### Workflow

1. Copy `$K/scripts/blender_plate.py` into the film's `blender/` folder. Replace `build()` (objects, materials) and `animate(f)` (every object's position as a pure function of the frame). Keyframing every frame from a function keeps the shot exact and re-timable.
2. Put the shot's big moment on a whole music beat: at 120 BPM and 30 fps, music beat `m` is frame `m × 15`. Cue the score to the same beat with `M(c)`.
3. Look before rendering: `blender -b -P blender_plate.py -- still 60 50` renders frame 60 at half size in seconds. Composite a few stills onto the brand ground with Pillow and read them.
4. Render: `blender -b -P blender_plate.py -- anim 100` (run it in the background; about 3 s a frame at 1080×1920 on an M1). Then `ln -s ../blender/renders/PLATE shots/PLATE` and in comp.html set `SHOTS={PLATE:{at:0,n:FRAMES,ext:'png'}}`.
5. In the comp, `plate('PLATE', scale, ox, oy)` draws the current frame. The plate plays in real time from its `at` beat, so a comp segment stretched in `timeline.js` does not stretch the plate: time the plate in seconds of music.

The Blender install on macOS: `/Applications/Blender.app/Contents/MacOS/Blender`.

### Looks that work

- **Transparent film, dark world at low strength.** The world lights and reflects but the comp draws the ground, so the plate sits on any background, gradient or photo.
- **Three area lights:** a warm key top-left, an accent-coloured rim from behind (it separates objects from a dark ground), a faint cool fill. AgX with "Medium High Contrast".
- **Shallow focus** (f/1.1–1.4) with objects spread in depth: the far ones soften, so text can sit over the plate. Put a soft dark pool (`halo()` in comp.html) behind text rather than a full-frame scrim.
- **Motion blur on** (`motion_blur_shutter = 0.5`) for anything that moves fast.
- **Bloom** is gone from EEVEE since 4.2. Set `BLOOM` in the template to add the compositor Glare node, or add glow in the comp (`shadowBlur`, `lighter` blending), which is easier to time.
- **Real reflections:** a CC0 HDRI from Poly Haven as the world. Poly Haven, ambientCG and Kenney assets are CC0 and safe for ads; check Sketchfab models one by one.

### Physics plates

What Claude does best in Blender is motion that a simulation or a formula drives: a domino chain, a logo knocked over at the end of it, a jelly wobble, a flag in the wind, parts dropping into place. Rigged characters, walk cycles and acting come out wrong (flipped hands, crossing feet, stiff walks) in every published test: take those from a generated plate.

In `blender_plate.py`, make each simulated object with `rigid(o, mass=…, friction=…, shape=…)` (ground and walls `'PASSIVE'`); they go in `SIM`, which is never keyframed. The script bakes the cache before rendering, so a `still` and every split `anim` run read the same simulation. Keyframe only the camera, and drive it from the baked result: step the frames, find where the action is (the domino that has just tipped) and put the camera and its target there.

Values that work, from Aidan Stanik's published domino prompt:

- Dominoes 1:2:4 (wide:deep:tall), spaced at 0.6× their height, 0.2 kg, friction 0.7, bounce 0, `'BOX'` collision; 20–40 substeps and 20 solver iterations.
- The first piece tipped past its balance point (22° for a 1:2:4 block) with kinematic keyframes for a few frames, then released to physics.
- A text logo at the end as a mesh, `'CONVEX_HULL'` collision, 0.35 kg, facing away from the chain so the last domino hits its back.
- Soft body jelly: mass 0.8, goal spring 0.5, pull and push 0.9, bend 8, damping 0.05; a Collision modifier on the ground.
- Cloth in wind: wind strength has to be far higher than looks sensible (one creator needed 5,000); raise it until the flag whips.

Verify by sampling the bake, not by looking: `sc.frame_set(f)` and read `o.matrix_world` (how many pieces have tipped by frame 90, whether the logo ends upright) before any render.

### Handing 3D to a flat logo

Render the last frame of the plate, cut it out (`alpha < 60 → 0`) and crop it square around the object into `assets/`, so it can be drawn at any size without the plate's soft shadow showing as a box. Measure its size in pixels from the alpha bounding box, scale it so it matches the supplied logo mark exactly, then slide it into the lockup position and crossfade to the flat mark over half a beat. A shockwave ring on the landing hides the swap.

## Generated plates

A person, a character, a crowd or a real place you have no footage of comes from a video model (Seedance, Kling, Veo, Runway; `higgsfield-generate` if installed). The most-watched films of this style are hybrids: the model supplies faces, bodies and physics; the comp supplies every word, the timing, the brand and the transitions.

- Prompt for a clean plate: the shot, the camera move, the light, the aspect ratio of the film, "no text, no captions, no logos, no watermark", and room in the frame where the type will sit.
- Keep shots short (5–10 s) and generate each at the film's aspect ratio; say what happens second by second. Blocking the camera move in Blender first and handing the playblast over as a reference cuts re-prompting.
- Bring it in with `prep_footage.sh` like any footage, `mask:true` for text behind the person, and cut on the beat in the comp.
- Say in delivery which shots are generated, and never use a real person's face or a client's product in a generation without their consent.

## Traps

| Trap | Fix |
|---|---|
| Spheres or shapes cut square in the comp | The crop around the 3D object is tighter than the object: measure the alpha bounding box and crop wider |
| Swarm of identical bright objects fights the text | Fewer objects, a spread of sizes, deeper field, darker world; dim a pool behind the words |
| `scene.node_tree` errors on 5.x | Compositor is `scene.compositing_node_group` (a `CompositorNodeTree` with a Group Output); Glare options are input sockets |
| PNG output setting ignored on 5.x | Set `image_settings.media_type = 'IMAGE'` before `file_format` |
| Every piece's origin at the world origin after scaling | `transform_apply(scale=True)` also applies location and rotation (all three default to on): pass `location=False, rotation=False, scale=True` |
| Dominoes fall short or the chain stalls | Spacing too wide for the height (keep it near 0.6×) or too few substeps |
| Blender MCP servers | Useful for looking at a scene live, but they run arbitrary Python with no guard; the headless script is enough for rendering |
