# 3D plates with Blender

A 3D plate is a Blender shot rendered headless to a **transparent PNG sequence**. The comp plays it like footage, so the 3D work and the motion graphics stay in one timeline: the comp can scale, lift and shake the plate, draw text and shockwaves over it, and hand a 3D object into a flat logo. Use it when a shape needs real light, depth of field or physical motion (a logo that assembles, a product that turns, a swarm that forms a mark). For flat, graphic motion the canvas is faster and needs no plate.

## Workflow

1. Copy `$K/scripts/blender_plate.py` into the film's `blender/` folder. Replace `build()` (objects, materials) and `animate(f)` (every object's position as a pure function of the frame). Keyframing every frame from a function keeps the shot exact and re-timable.
2. Put the shot's big moment on a whole music beat: at 120 BPM and 30 fps, music beat `m` is frame `m × 15`. Cue the score to the same beat with `M(c)`.
3. Look before rendering: `blender -b -P blender_plate.py -- still 60 50` renders frame 60 at half size in seconds. Composite a few stills onto the brand ground with Pillow and read them.
4. Render: `blender -b -P blender_plate.py -- anim 100` (run it in the background; about 3 s a frame at 1080×1920 on an M1). Then `ln -s ../blender/renders/PLATE shots/PLATE` and in comp.html set `SHOTS={PLATE:{at:0,n:FRAMES,ext:'png'}}`.
5. In the comp, `plate('PLATE', scale, ox, oy)` draws the current frame. The plate plays in real time from its `at` beat, so a comp segment stretched in `timeline.js` does not stretch the plate: time the plate in seconds of music.

The Blender install on macOS: `/Applications/Blender.app/Contents/MacOS/Blender`.

## Looks that work

- **Transparent film, dark world at low strength.** The world lights and reflects but the comp draws the ground, so the plate sits on any background, gradient or photo.
- **Three area lights:** a warm key top-left, an accent-coloured rim from behind (it separates objects from a dark ground), a faint cool fill. AgX with "Medium High Contrast".
- **Shallow focus** (f/1.1–1.4) with objects spread in depth: the far ones soften, so text can sit over the plate. Put a soft dark pool (`halo()` in comp.html) behind text rather than a full-frame scrim.
- **Motion blur on** (`motion_blur_shutter = 0.5`) for anything that moves fast.
- **Bloom** is gone from EEVEE since 4.2. Set `BLOOM` in the template to add the compositor Glare node, or add glow in the comp (`shadowBlur`, `lighter` blending), which is easier to time.
- **Real reflections:** a CC0 HDRI from Poly Haven as the world. Poly Haven, ambientCG and Kenney assets are CC0 and safe for ads; check Sketchfab models one by one.

## Handing 3D to a flat logo

Render the last frame of the plate, cut it out (`alpha < 60 → 0`) and crop it square around the object into `assets/`, so it can be drawn at any size without the plate's soft shadow showing as a box. Measure its size in pixels from the alpha bounding box, scale it so it matches the supplied logo mark exactly, then slide it into the lockup position and crossfade to the flat mark over half a beat. A shockwave ring on the landing hides the swap.

## Traps

| Trap | Fix |
|---|---|
| Spheres or shapes cut square in the comp | The crop around the 3D object is tighter than the object: measure the alpha bounding box and crop wider |
| Swarm of identical bright objects fights the text | Fewer objects, a spread of sizes, deeper field, darker world; dim a pool behind the words |
| `scene.node_tree` errors on 5.x | Compositor is `scene.compositing_node_group` (a `CompositorNodeTree` with a Group Output); Glare options are input sockets |
| PNG output setting ignored on 5.x | Set `image_settings.media_type = 'IMAGE'` before `file_format` |
| Blender MCP servers | Useful for looking at a scene live, but they run arbitrary Python with no guard; the headless script is enough for rendering |
