# The brand layer

The parent skill is the craft. It names no colour, typeface, motif, logo or canvas size on purpose. A **brand layer** supplies those, and it is a plug-in: swap it and the same craft produces a different brand's work.

**Load the brand's own document alongside the skill before designing anything.** Without it the craft still runs and produces competent, faceless work — that is the intended failure, not a bug.

## The split test

When a rule appears and you are deciding which layer owns it:

- Names a token, typeface, motif, logo, palette, market or file → **brand layer**.
- Names a *decision sequence* or a *failure you can check for* → **craft**.
- Would still be true after a rebrand → **craft**.

## Slots a brand layer must fill

A brand layer is complete when it answers all of these, and it should contain **only** these.

| Slot | The question it answers |
|---|---|
| Ground | What is the default surface, and what is the exception? |
| Palette | Which values exist, which are forbidden, what does the accent mean and where is it spent? |
| Type | Which faces, which scale, which face does which job? |
| Legibility | How does text hold on an image in this brand — fade, ground split, panel, quiet zone? Which is default? |
| Component language | The recurring objects: lockups, marks, panels, chips. |
| Imagery | Subject matter, treatment, who appears, what never appears. |
| Mark and co-branding | How the mark is placed, when a second brand joins, how they are divided. |
| Numbers | Margins, safe area, canvas sizes, the size set that ships. |
| Casing and naming | How the brand's own name is written, and the export naming scheme. |
| **Voice** | Where the words come from and who signs them off. Name the brand's voice document or skill, and the lines it forbids. |
| **Proportion** | The size ratio a secondary segment holds against the leading one, and which channel carries hierarchy — size, weight, space or colour. |
| Corrections ledger | Dated preferences caught on real work. The section that keeps growing. |

**The voice slot is not optional and it is the one most often left empty.** No check in the craft skill audits meaning: a line that blames the reader, overclaims, or breaks the brand's own forbidden formulations will pass every computed and visual check on the asset. On a real run, a cold agent with a complete brand layer that had no voice slot reproduced a formulation the brand had explicitly banned nine months earlier — and nothing caught it. Name the voice owner here, or the words ship unreviewed.

## Rules for writing one

- **Every line traces to a correction someone actually made on real work.** A brand layer assembled from taste in the abstract will contain rules that contradict the brand's own direction. This has happened: a third of an earlier draft was inherited from an unrelated brand's system on the theory that a rule appearing in two documents must be principle, and three of those rules turned out to instruct against what the brand owner wanted. **Two documents agreeing is not validation.**
- **No tool property names.** Write design values — blur 40, corner radius 24 — not the API keys of whatever editor was in use. The layer must survive changing tools.
- **Date every entry and never silently edit one.** A reversal is a new dated line naming what it overturns.
- **One owner.** If the same rule appears in two documents, one of them is stale and the ambiguity will be resolved wrongly by whoever reads first.

## Rules for using one

- Read it before designing, not after.
- Where the brand layer and the craft conflict, **the brand layer wins on values and the craft wins on method.** A brand may say panels are banned; it may not say ranking is optional.
- A community or sub-brand lockup is not the parent brand's lockup. Putting one on the other's commercial work misattributes it.

## Which gaps you may fill, and which you must not

A brand layer will arrive incomplete — most are written in an afternoon by someone who is not a designer. **The line is whether filling it invents the brand.**

| Slot | If empty |
|---|---|
| Margin, safe area, spacing scale | **Fill it.** Pick one, write it down, hold it across the set. Reversible, layout-level. |
| Proportion ratio, hierarchy channel | **Fill it.** Same. Record it so the next asset matches. |
| Canvas sizes for a format not listed | **Fill it** from the channel's standard. |
| **Typeface family** | **Escalate.** Never substitute. A brand whose identity is its typeset name *is* its typeface. |
| **Any colour value** | **Escalate.** An unpublished colour cannot be contrast-checked. |
| **A person's name, a URL, a legal or price fact** | **Escalate.** Leave a placeholder that cannot be mistaken for real. |
| **The mark itself** | **Escalate.** Never draw, redraw or reconstruct one. |

Filling an escalate-only slot fabricates the brand. Filling a fillable slot and *not* recording it is how the next asset drifts.

## When the brand mandates something that fails

A brand layer can require an illegible combination — its own text colour on its own field colour, a size below its own minimum. **Break the rule loudly.** State the measured contrast, state the minimum change that fixes it, apply that change, mark it as requiring the owner's sign-off, and log it as a proposed ledger entry. Never ship the illegible version, and never fix it silently — a silent fix becomes an undocumented brand rule nobody agreed to.
